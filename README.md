# Sentiment Analysis Project

This repository contains an academic sentiment analysis project developed in Python.

## Project Overview
The project focuses on text classification and sentiment analysis using Python-based data processing and machine learning techniques.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- Scikit-learn
- WordCloud

## Repository Structure
- `HS_Project_Z.py` → main project script
- `results/` → output figures or result files
- `requirements.txt` → required Python libraries
- `README.md` → project documentation

## How to Run
Install the required libraries first:

```bash
pip install -r requirements.txt
python HS_Project_Z.py
